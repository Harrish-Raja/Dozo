# Dozo · Dose done.

Interactive prototype of **Dozo**, the smart pillbox for grandparents, built for our Shark Tank pitch. All data is mock data.

**Pages:** Home · Live demo (pillbox + family phone, voice in English, Tamil and Hindi) · Family app dashboard · Care-home dashboard · Pricing and pre-order.

## Deploy on GitHub Pages
1. Upload `index.html`, `404.html` and `.nojekyll` to the root of this repo.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
3. Open `https://harrish-raja.github.io/Dozo/` after a minute.
